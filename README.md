# 四角色 agent 协作骨架

分析 → 产品 → 开发 → 测试 → 你验收 → 上线。
记忆放在文件里,对话随用随开,每个角色、每个任务新开一个对话。

**怎么用,请看 [使用手册.md](使用手册.md)。**

## 目录

| 路径 | 作用 |
|---|---|
| `AGENTS.md` | 所有 agent 先读:通用规则、角色指派、门禁、权限 |
| `docs/rules/` | 五个角色的职责与禁区:分析、产品、开发、测试、维护 |
| `docs/standards/` | 产品、开发、测试规范清单,以及 `INDEX.md`(来源与沉淀台账) |
| `docs/00` 至 `docs/04` | 各阶段文档模板 |
| `docs/issues.md` | 问题回流单 |
| `docs/changes/` | 首次上线后的变更文件夹与模板 |
| `scripts/check_paths.py` | 检查角色有没有改不该改的文件 |
| `scripts/new_change.py` | 创建变更文件夹 |
| `使用手册.md` | 给负责人的完整操作流程 |
| `提示词库.md` | 通用提示词:读仓库(P0)、产出模板文件(P1)、排版整理(P2) |
| `docs/rules/format.md` | 文档排版规范,所有角色适用 |
